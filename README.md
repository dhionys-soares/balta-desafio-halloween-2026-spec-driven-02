### Sobre este desafio

Neste desafio o objetivo é criar um encurtador de URLs completo utilizando os conceitos de Spec-Driven Development

#### O que foi implementado

- API de encurtamento de URLs em .NET 10 com Minimal API.
- Geração automática de códigos de 7 caracteres e suporte a códigos personalizados.
- Validação de URLs HTTP/HTTPS públicas e de códigos permitidos.
- Redirecionamento para o destino, com contagem atômica dos acessos.
- Expiração de links considerando a data em UTC.
- Consulta de estatísticas protegida por chave de gerenciamento armazenada como hash.
- Persistência dos links em SQLite com Entity Framework Core.
- Testes unitários e de integração com xUnit.

Neste processo eu aprendi:

* ✅ Aplicar Spec-Driven Development para transformar requisitos em tarefas e implementação.
* ✅ Criar APIs Minimal API em .NET e organizar regras de negócio em serviços.
* ✅ Persistir dados com Entity Framework Core e SQLite.
* ✅ Validar comportamento com testes unitários e de integração.

## Problema

Links longos podem ser difíceis de compartilhar em mensagens, e-mails e materiais impressos. Este projeto permite criar links curtos, redirecionar visitantes para o destino original e consultar a quantidade de acessos com uma chave de gerenciamento.
